Termos de uso e privacidade

Agenda Fácil é um projeto acadêmico. Este texto descreve, de forma simples, como a plataforma funciona.

1. Sobre o Agenda Fácil

O Agenda Fácil conecta clientes a profissionais que oferecem serviços. O cliente escolhe um serviço, um profissional, uma data e um horário disponível. O profissional define seus serviços e horários e administra os agendamentos que recebe.

2. Contas

  • Existem dois tipos de conta: cliente e profissional.
  • Você é responsável por manter sua senha em segurança e por informar dados verdadeiros.
  • Profissionais informam o endereço do local de atendimento, que é exibido aos clientes.

3. Agendamentos

  • Só é possível escolher horários que o profissional deixou disponíveis.
  • Um agendamento começa como pendente, pode ser confirmado pelo profissional e depois concluído. Também pode ser cancelado.
  • Cancele com antecedência, para que o horário volte a ficar livre para outras pessoas.

4. Localização

Para mostrar profissionais próximos, o Agenda Fácil poderá usar a sua localização, somente com a sua permissão. Você pode negar o acesso e informar um endereço ou CEP manualmente.

5. Privacidade e dados

  • Coletamos apenas os dados necessários: nome, e-mail, telefone, endereço do profissional e histórico de agendamentos.
  • O profissional vê apenas os clientes que agendaram com ele; o cliente vê apenas os próprios agendamentos.
  • A autenticação é feita pelo Firebase Authentication, e os dados do sistema ficam em banco de dados protegido por uma API.

6. Limitações

Por ser um projeto acadêmico, o serviço pode ser alterado ou ficar indisponível, e os dados exibidos durante o desenvolvimento são apenas exemplos.
